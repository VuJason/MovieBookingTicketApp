========================================
API ENDPOINTS
========================================

1. POST /bookings/{id}/zalopay-payment
   - Tạo payment
   - Response: { order_url, zp_trans_token, return_code }

2. POST /payment/webhook/zalopay
   - ZaloPay webhook callback
   - Auto update status to CONFIRMED

3. PUT /bookings/{id}/confirm
   - Manual confirm (backup)
   - Response: { message, status, confirmedAt }

4. GET /bookings/{id}
   - Get booking status
   - Response: { bookingId, status, totalAmount, ... }
