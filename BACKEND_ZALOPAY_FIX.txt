HƯỚNG DẪN SỬA BACKEND CHO ZALOPAY
========================================

VẤN ĐỀ HIỆN TẠI:
✅ Payment URL đã OK (không còn NULL)
⚠️ Booking vẫn PENDING (chưa CONFIRMED)
⚠️ Không redirect về app sau khi thanh toán

GIẢI PHÁP:

CÓ 2 CÁCH CONFIRM BOOKING:
1. Webhook (tự động) - Cần public URL (ngrok)
2. Manual API (backup) - Frontend tự gọi sau khi thanh toán

Frontend đã tích hợp cả 2 cách!

3. XỬ LÝ WEBHOOK CALLBACK
==========================

QUAN TRỌNG: Webhook này được ZaloPay gọi TRỰC TIẾP từ server của họ.
Không phải từ mobile app!

@PostMapping("/webhook/zalopay")
public ResponseEntity<?> handleZaloPayCallback(@RequestBody Map<String, Object> callbackData) {
    try {
        System.out.println("=== ZaloPay Webhook Received ===");
        System.out.println("Callback data: " + callbackData);
        
        // Verify MAC
        if (!zaloPayService.verifyCallback(callbackData)) {
            System.err.println("MAC verification failed!");
            return ResponseEntity.ok(Map.of(
                "return_code", -1,
                "return_message", "MAC verification failed"
            ));
        }

        // Parse data
        String dataStr = callbackData.get("data").toString();
        Map<String, Object> data = gson.fromJson(dataStr, Map.class);
        String appTransId = data.get("app_trans_id").toString();
        Long bookingId = Long.valueOf(appTransId.split("_")[1]);

        System.out.println("Booking ID: " + bookingId);

        // Update booking status
        Booking booking = bookingRepository.findById(bookingId).orElseThrow();
        System.out.println("Current booking status: " + booking.getStatus());
        
        booking.setStatus("CONFIRMED"); // ← QUAN TRỌNG: Đổi sang CONFIRMED
        booking.setPaymentTime(LocalDateTime.now());
        bookingRepository.save(booking);
        
        System.out.println("Booking updated to CONFIRMED");

        // Send email confirmation
        try {
            emailService.sendBookingConfirmation(booking);
            System.out.println("Email sent successfully");
        } catch (Exception e) {
            System.err.println("Failed to send email: " + e.getMessage());
            // Don't fail the whole callback if email fails
        }

        return ResponseEntity.ok(Map.of(
            "return_code", 1,
            "return_message", "success"
        ));
    } catch (Exception e) {
        System.err.println("Webhook processing failed: " + e.getMessage());
        e.printStackTrace();
        return ResponseEntity.ok(Map.of(
            "return_code", 0,
            "return_message", "Processing failed: " + e.getMessage()
        ));
    }
}

KIỂM TRA WEBHOOK:
- Webhook URL phải public (không phải localhost)
- Nếu đang dev local, dùng ngrok: ngrok http 8080
- Cập nhật callback_url trong ZaloPay config
- Check logs xem ZaloPay có gọi webhook không

5. API GET BOOKING STATUS (ĐÃ CÓ)
===================================

@GetMapping("/bookings/{id}")
public ResponseEntity<?> getBookingById(@PathVariable Long id) {
    try {
        Booking booking = bookingRepository.findById(id).orElseThrow();
        return ResponseEntity.ok(booking);
    } catch (Exception e) {
        return ResponseEntity.status(404).body(Map.of(
            "message", "Booking not found"
        ));
    }
}

6. API MANUAL CONFIRM (ĐÃ CÓ) ✅
=================================

Đây là backup khi webhook không hoạt động:

@PutMapping("/{bookingId}/confirm")
public ResponseEntity<?> confirmBookingPayment(@PathVariable Long bookingId) {
    try {
        Booking booking = bookingService.confirmBookingPayment(bookingId);
        return ResponseEntity.ok(Map.of(
            "message", "Đã xác nhận thanh toán thành công",
            "bookingId", booking.getId(),
            "status", booking.getStatus(),
            "confirmedAt", LocalDateTime.now()
        ));
    } catch (RuntimeException e) {
        return ResponseEntity.badRequest().body(Map.of(
            "error", e.getMessage(),
            "bookingId", bookingId
        ));
    }
}
